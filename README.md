## 🚀 Usage & CDN Integration

### Raw GitHub URL
```html
<img src="https://raw.githubusercontent.com/<user>/<repo>/main/icons/wallets/paypal.svg" height="32" alt="PayPal" />
```

### jsDelivr CDN
```html
<img src="https://cdn.jsdelivr.net/gh/<user>/<repo>@main/icons/cards/visa.svg" height="32" alt="Visa" />
```
